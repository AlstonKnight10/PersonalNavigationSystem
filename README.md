# Personal Navigation System

A Java-based navigation system that uses geographic and simulated GPS data to calculate and display routes.

## Features

- Shortest-path route calculation
- GPS position processing
- Map matching
- Route recalculation
- Geographic data processing
- Graph-based navigation
- Graphical user interface

## Project Structure

The project is organized into several packages:

- `app` - Application entry points and coordination
- `dataprocessing` - Processing and loading geographic data
- `feature` - Navigation-related features
- `geography` - Geographic data structures
- `gps` - GPS data and position handling
- `graph` - Graph structures and routing algorithms
- `gui` - User interface components
- `math` - Mathematical utilities

## Technologies

- Java
- Graph algorithms
- GPS and geographic data
- Git / GitHub

## Data

The repository includes several geographic and GPS datasets used for testing navigation and routing behavior.

## About

This project was developed as a software engineering project focused on applying graph algorithms, geographic data processing, and simulated GPS input to a navigation system.
